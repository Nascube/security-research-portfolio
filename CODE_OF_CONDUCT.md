# Code of Conduct

This is a small personal educational repository. The rules here are short on
purpose and are enforced by the maintainer.

## The rules

1. **Be respectful and precise.** Assume good faith. Disagree with ideas, not
   with people.
2. **Stay on scope.** This repository is defensive and educational — see
   [Responsible use](README.md#responsible-use). Requests, issues, and PRs
   that push it outside that scope will be closed.
3. **No harassment.** Personal attacks, slurs, targeted insults, sustained
   disruption, and doxxing are grounds for immediate removal.
4. **No fabricated claims.** Do not open issues or PRs that assert
   discoveries, incidents, or credentials that cannot be verified. See
   [Research integrity](docs/research-integrity.md).
5. **Report suspected security problems privately** via
   [`SECURITY.md`](SECURITY.md), not in public issues.

## Scope

This code applies to every space directly associated with the repository:
issues, pull requests, discussions, commit messages, and any communication
that references this project.

## Enforcement

The maintainer may, at their discretion:

- Ask for a message to be edited or withdrawn.
- Close or lock an issue or pull request.
- Block a contributor from further participation.

Actions are logged in the affected issue or PR so the record is visible.

## Reporting

Concerns about conduct in this repository can be raised by:

- Opening a regular issue if the concern is not sensitive.
- Contacting the maintainer privately via the address listed on their GitHub
  profile if the concern involves an individual and should not be public.

There is no bug bounty and no service-level agreement — reports are handled
on a best-effort basis by a single maintainer.

## Attribution

This document is written from scratch for this repository. It is deliberately
narrower than the Contributor Covenant, matching the size and scope of the
project.
